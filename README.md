## 📌 Project Overview

This project satisfies all requirements specified in **Task 3** and **Task 1** of the SAM AI Technologies internship curriculum. It is designed to serve as a central hub showcasing technical competencies, real-world internship projects (including Task 2 To-Do App and Task 4 Music Player), education credentials at **REVA University, Bangalore**, downloadable resume PDF, and a validated contact channel.

---

## ✨ Key Features

- **📱 Fully Responsive Design**: Seamless layout scaling from mobile viewports (320px+) to large desktop monitors.
- **🌓 Dark & Light Mode Theming**: Dynamic theme switching with automatic system preference detection and `localStorage` persistence.
- **⚡ Smooth Scrolling & Scroll Spy**: Intelligent navigation header that tracks the active section and updates links in real-time.
- **📂 Interactive Projects Showcase**: Structured project cards featuring task badges, tech stack tags, live preview links, and GitHub links.
- **📄 Resume Download & Preview**: Direct one-click download for `Ajay_Hukkeri_Resume.pdf` with browser viewing option.
- **🛡️ Client-Side Form Validation**: Real-time error feedback for input fields (name, email format regex, subject, message) and interactive toast notifications.
- **🎨 Modern Aesthetic**: Glassmorphism header backdrop, CSS custom variables, custom hover micro-interactions, and accessible typography.

---

## 🛠️ Technology Stack

- **Markup**: Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **Styling**: Modern CSS3 (CSS Variables, Flexbox, CSS Grid, Transitions, Keyframes)
- **Scripting**: Vanilla JavaScript (ES6+ modular DOM manipulation, Event Listeners, Web Storage API)
- **Typography & Icons**: Google Fonts (*Plus Jakarta Sans*, *Fira Code*), FontAwesome 6

## 🚀 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ajayhukkeri6363-cpu/sam-ai-developer-portfolio.git
   cd sam-ai-developer-portfolio/portfolio
   ```

2. **Run locally**:
   - Open `index.html` directly in any modern web browser.
   - Or launch with VS Code Live Server / Python HTTP server (`python -m http.server 8000`).

---

## 🌐 Live Deployment Instructions

### GitHub Pages (Recommended)
1. Push your repository to GitHub.
2. Navigate to repository **Settings** -> **Pages**.
3. Under **Branch**, select `main` and root folder `/` (or `/portfolio`), then click **Save**.
4. Your site will be published at `https://ajayhukkeri6363-cpu.github.io/sam-ai-developer-portfolio/`.
